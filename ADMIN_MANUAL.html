VERSION 4 VERIFIED ARCHITECTURE

Administrator Manual — System Governance & Diagnostics

This manual covers administrative governance, dynamic monthly coupon distribution, student voice enrollment, and DSP engineering inspection for Final project v4.

1. Launching & Logging In

  1. Launch MATLAB R2024a+ and set Current Folder to Final project v4.
  2. Execute: run_meal_system in the Command Window.
  3. Select the Admin tab.
  4. Enter Admin ID (default demo: admin) and Password (default demo: admin).
  5. Press Unlock / meal log. Upon successful authentication, administrative controls and tables are activated.
CRITICAL SECURITY PROTOCOL: Never leave the Admin tab unlocked at a public dining counter! The unlocked interface exposes private meal records, student names, timestamps, and acoustic distance scores. Always press Lock before stepping away.

2. Dynamic Monthly Coupon Administration (v4 Architecture)

In Version 4, the system has transitioned to a single source of truth: the dynamic monthly coupon registry. Static code.txt files have been permanently eliminated from the verification path.

Monthly Token Distribution Workflow:
  1. When a student pays their monthly dining fee, navigate to the Admin tab.
  2. Under Assign coupon, enter the 7-digit Student ID (e.g. 2206147) and generate/enter a unique 6-digit code.
  3. Press Assign for current month. The system writes an active record to MonthlyCouponRegistry.csv.
  4. Provide the 6-digit code to the student. When they present at the counter for their first meal of the month, typing this code verifies their payment and unlocks their dining entitlement for the entire 30-day billing cycle.
  5. Press Coupon registry to view assigned codes, active months, and consumed timestamps.

4. Student Enrollment & Voice Import (v4 Updates)

Press Open DSP workspace to construct the private New Enroll tab:

  • Decoupled Credentials: Version 4 does not ask for a coupon during enrollment. Enrollment captures vocal identity profiles only (Spoken ID and Spoken Name).
  • Automated Live Enrollment: Press New Enroll to record 3 ID takes and 3 Name takes. Each take is strictly validated by assess_recording_quality.m. Usable takes are stored under Train/ID/<id> and Train/Name/<id>.
  • Multi-File WAV Take Import (New in v4): Press Import .wav file(s)... to select individual .wav files using Windows multi-select. The importer automatically converts audio to mono, resamples to 8 kHz, checks speech SNR/clipping, and saves valid files sequentially.
  • Template Cache Reset: Press Reload template cache after adding new files to clear in-memory buffers so the matcher recognizes new students immediately.
